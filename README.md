# sahali-gen

Hi! I'm insectivore, and this is a very small project that fits into my larger hobby of worldbuilding & character creation.

As of current, **sahali-gen** is in beta. I don't have releases or anything set up yet

**Sahalis** are members of my fictional anthropomorphic species, the Sahalians. I have a looooot of worldbuilding done on them
but none of it is public yet, which is why this is currently completely out of context. It will make more sense once I make the
multitudes of documents on the Sahalian species available on my page. For now I'm just making this project for myself. All you
need to know is that this is a basic generator that creates a randomized Sahalian character, listing basic physical and personality
traits with each new generation.

## requirements:
- platform: N/A (that I know of)
- software: Python interpreter, rich library (this isn't an .exe yet)

## how to run:
For now, this is a terminal-based game. It will hopefully have a GUI in the future...

Simply download the file(s), cd into the directory you downloaded them to, and run the command

```python sahali-gen.py```
